Features / Efficacy Evaluation

Features / 人体効能評価

  • 55〜75歳の男女を対象に、12週間のヒト試験を行いました。
  • 記憶を保つ力を高め、神経細胞の炎症を抑えます。
  • 睡眠の質・効率が上がり、シナプス可塑性の向上によって記憶力や学習能力が高まります。
  • 即時想起力が向上し(SVLT総点でP<0.01)、記憶力低下に関わる血液指標AChEが減少しました。
