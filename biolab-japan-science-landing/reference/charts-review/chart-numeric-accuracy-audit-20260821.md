# 차트 수치 정확도 감사 (Chart numeric accuracy audit)

작성일: 2026-08-21
대상 파일:

- `src/lib/evidenceCharts.ts` (ported BUILD)

## 감사 기준

1. **부호(Sign)** — 값이 0을 기준으로 올바른 방향(위/아래)에 있는가
2. **상대 크기(Relative)** — 섭취군 vs 위약군의 대소 관계가 논문/캡션과 맞는가
3. **정확값(Exact)** — 논문 표에 수치가 있는 경우 그 값과 정확히 일치하는가

Exact 수치가 있는 경우 이미지 디지타이징보다 논문 표를 우선했습니다.

## 3. Approx로 남기되 방향이 틀렸던 항목

1. **`nvp2106-evidence-2` Q4 지연 단어회상 — 위약 종점 부호**
   캡션은 "위약 대비 1,514% 개선"인데 위약 종점이 `+0.05`(악화)였습니다. 위약이 악화하면 "몇 % 개선"이라는 비율 자체가 성립하지 않습니다. NVP 변화량 −0.90 ÷ 15.14 = −0.059이므로 위약은 0보다 **약간 아래**여야 합니다. 값을 0 아래로 옮겼지만 **여전히 Approx**입니다. 원본 이미지를 확보해 확정하는 것이 좋습니다.

2. **`med01-evidence-1` 질작열감 — 위약이 정확히 0**
   논문 본문은 위약군에서 작열감이 증가했다고 명시합니다. `+0.1`은 Figure 3B에서 읽은 근사값이며 표 수치가 없으므로 **Approx 유지**입니다.

3. **`applephenon-evidence-1` y축 라벨**
   좌표 자체는 원본 이미지와 정확히 일치하지만, J Oleo Sci Table 7의 어떤 항목과도 매칭되지 않습니다 (체지방률 Δ는 +0.2/+0.3/+0.5/+1.8로 부호가 반대, 체중 Δ는 +0.3/−0.5/−0.9/−0.3으로 스케일이 다름). 현재 라벨 `체지방 지표 변화`는 **출처 미확인 추정치**입니다. 수치는 그대로 두되 라벨을 단정적으로 쓰지 않는 편이 안전합니다.

4. **`nvp1702-evidence-2` γ-GTP 6주 시점**
   NVP-1702가 `+1`(악화)로 들어가 있습니다. 회사 PDF는 12주 감소만 기술하므로 6주 부호는 근거가 없습니다. 방향성 위험은 낮지만 Approx 유지 대상입니다.
