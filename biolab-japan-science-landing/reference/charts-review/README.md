# BIOLAB 근거 차트 참조 프로젝트

이 폴더는 BIOLAB Japan 제품 상세 페이지의 원본 근거 차트와 HTML/SVG 재현본을 나중에 참고하기 위한 보관본입니다.

## 파일

- `charts-review.html`: 원본 이미지와 HTML/SVG 재현 차트를 좌우로 비교하는 메인 페이지입니다.
- `chart-accuracy-only-audit.md`: 차트 정확도 중심 검수 기록입니다.
- `chart-visual-source-audit-report.md`: 원본 이미지와 시각 구조 검수 기록입니다.
- `graph-source-reference-map-20260707.md`: 그래프별 원자료·출처 연결표입니다.
- `paper-chart-values-audit-20260707.md`: 논문·PPTX·PDF 수치 대조 기록입니다.
- `vision-graph-accuracy-audit-20260707.md`: 원본 그래프와 HTML 재현본의 형태 검수 기록입니다.

## 사용 방법

`charts-review.html`을 브라우저에서 열면 원본 이미지는 현재 `biolabjp.com`에 배포된 이미지에서 불러옵니다. 상단에서 KR/JP/EN 언어와 폭을 바꿀 수 있습니다.

이 참조본은 현재 제품 상세 페이지에 차트를 반영한 것이 아니며, 차트 원본과 HTML 재현 결과를 비교하기 위한 자료입니다.

원본 캡처·PPTX 추출물·논문 PDF는 저장소 용량을 불필요하게 키우지 않기 위해 이 폴더에 복사하지 않았습니다. 원자료 경로와 판단 근거는 각 검수 문서에 기록되어 있습니다.
