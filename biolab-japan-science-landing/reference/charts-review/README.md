# BIOLAB 근거 차트 참조 프로젝트

원본 근거 차트와 HTML/SVG 재현본을 좌우로 비교하는 보관본입니다.

## 바로 보기

- **비교 HTML (배포):** https://biolabjp.com/dev/charts-review.html  
- 저장소 원본: `charts-review.html`  
- Exact 교차검증 보고서: `multi-model-cross-verify-2026-08-21.md`

## 파일

- `charts-review.html`: 원본 이미지 ↔ HTML/SVG 재현 비교 (교차검증 Exact·부호 반영)
- `multi-model-cross-verify-2026-08-21.md`: Opus/GPT/Sonnet 교차검증 합의
- `chart-numeric-accuracy-audit-20260821.md`: 1차 전수 감사
- 기타 `*-audit*.md` / 맵 문서: 과거 검수 기록

## 사용 방법

브라우저에서 비교 HTML을 열면 원본 이미지는 `biolabjp.com` 배포 이미지에서 불러옵니다. 상단에서 KR/JP/EN·폭을 바꿀 수 있습니다.

이 문서는 **원본↔재현 비교용**이며, 라이브 제품 상세 SVG는 「퍼블리시」 전까지 바꾸지 않습니다. `/dev/charts-approx` 초안과 수치가 동기화되어 있습니다.
