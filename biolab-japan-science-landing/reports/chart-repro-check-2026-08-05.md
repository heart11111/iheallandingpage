## 3. 잔여 항목 (경미 — 필요 시 다음 단계)

**3-A. ThinkGIN AChE 절단축 미구현 (경미)**
- 원본은 막대에 물결형 축 단절(broken axis). 현재는 일반 막대(`yMin:-12`)로 표현 (line 169). 값(-8.7 / -11)과 유의표시는 있으나 원본의 절단축 형태는 미재현. 캡션에 `근사값(형태 재현)` 명시됨.

**3-B. Applephenon evidence-1과 evidence-2 데이터 중복 (경미~중요)**
- evidence-1(체지방 지표)과 evidence-2(허리둘레)가 **동일한 값 배열** `[0,-0.27,-0.48,-0.66,-0.40]`(위약 `[0,0,0.02,-0.03,0.05]`)을 공유 (line 179, 181). 서로 다른 두 그래프인데 값이 같아, 한쪽은 실제 원본값이 아닌 placeholder로 보임. evidence-3(16주 BMI)은 별도 정의됨. → 허리둘레/체지방 지표의 실제 수치 분리 필요.

**3-C. `근사값(형태 재현)` 다수 (설계상)**
- 이미지형 원본만 있는 항목(Testofen, ThinkGIN, NVP-1704, NVP-1703 등)은 캡션에 `근사값(형태 재현)`으로 정직하게 표기. Exact는 MED-02와 각 P값. → 공개 반영 시엔 이 라벨 유지 또는 원문표 재확보 후 확정 권장.

**3-D. NVP-1704 paired plot 단순화 (경미)**
- IL-6/BDNF 개별변화 패널이 개인별 다중선이 아니라 그룹 평균 2선. 원본의 개인별 분포 형태와는 다름(패널 자체는 존재).

**3-E. 레이아웃 우측 잘림 (렌더 확인 필요)**
