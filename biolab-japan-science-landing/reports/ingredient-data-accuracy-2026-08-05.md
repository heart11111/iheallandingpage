## 1. 수정 완료 (이미지·논문으로 검증한 명백한 오류)

### 1-1. NVP-1702 — 알코올성/비알코올성 데이터 라벨이 뒤바뀜  [수정완료 · 중요]

라이브 소재 상세에서 두 간(肝) 시험의 라벨이 서로 바뀌어 있었음. 실제 근거 이미지로 확인:

- `nvp1702-evidence-1.webp` = **알코올성** 시험 (γ-GTP −2.85±33.26, ALT −3.77±14.64, **P=0.0292 / 0.0332**) — 그런데 사이트는 `非アルコール性(비알코올성)`으로 표기.
- `nvp1702-evidence-2.webp` = **비알코올성** 시험 (ALT **P=0.0260/0.0397**, AST **P=0.0131**, γGTP **P=0.0229**) — 그런데 사이트는 `アルコール性(알코올성)`으로 표기.

논문 검수문서(paper-chart-values-audit)의 값 귀속과도 정확히 일치. 다음을 수정:
- `ingredientPptDetails.ts` NVP-1702 `features`의 효소 P값 세트를 올바른 시험에 재귀속.
- `ingredientPptDetails.ts` 두 evidence 캡션의 알코올성/비알코올성 라벨 교정.
- `CorporateParts.tsx` 한국어 캡션 2건 동일 교정.
- 인원수(비알코올성 93명·알코올성 70명)는 원래 정확 → 유지.

### 1-2. MED-01 — `排尿痛(生理痛)` 오기  [수정완료 · 보통]

`med01-evidence-1.webp` 캡션이 `排尿痛(生理痛)`. `排尿痛`=배뇨통(dysuria)이고 `生理痛`=생리통(월경통)으로 의미가 완전히 다름(한국어 캡션은 이미 `배뇨통`으로 정확). → `排尿痛`으로 수정.

## 2. 확인 요청 (충돌·근거 불명 — 미수정, 판단 필요)

### 2-1. MED-02 시험 인원 100명 vs 75명  [확인요청]

- 사이트: `evidenceTags: "100名"`, 상세 `過体重または肥満の成人100名`.
- 마케팅 Introducing 덱: 100명. 신형 QC 덱: **75명**. 상세 MED-02 PPTX(BMI 차트): **75명**(인제대 서울백병원, BMI 25~31.9).
- 성격: 100명은 등록/모집, 75명은 분석 완료로 보임(MED-01이 101 무작위/76 완료인 것과 유사 구조).
- 권고: 표기 기준을 하나로 통일. 다른 소재가 "무작위 등록 수"를 쓰므로 100 유지도 일관성은 있으나, 그래프 설명은 75가 원본과 맞음. **어느 수를 노출할지 확정 필요.**

### 2-2. MED-02 SCI 논문 편수 6편 vs 5편  [확인요청]

- 사이트·Introducing 덱: 6편. 신형 QC 덱: 5報. → 원본 논문 목록으로 6/5 확정 필요(현재 6 유지).

### 2-3. Pinitol 혈당(血糖) 1.2g/day 기능성  [확인요청]

- 사이트 intake: `肝臓の健康 300mg/day・血糖値の健康 1.2g/day`.
- 확보한 논문/검수문서(J Nutr Biochem 2019, 300mg/day, NAFLD)에는 **간 기능**만 확인됨. 피니톨의 한국 개별인정 기능성에 혈당이 포함될 수 있으나, 이번 확보 자료로는 `1.2g/day 혈당`의 출처 미확인 → 원본 개별인정 고시로 확인 필요.

### 2-4. 마케팅 덱 자체 오류(참고)  [정상 — 사이트는 올바름]

신형 QC 덱은 MED-01을 `100명·SCI 6편`으로 적었으나 실제 논문(Nutrients 2023, 15, 331)은 **101명·SCI 9편**이며 **사이트는 101/9로 올바르게 표기**함. → 신형 덱을 근거로 되돌리지 말 것.

## 3. 누락 후보 (사용자 결정: 현행 10종 유지 → 추가 안 함)

마스터 덱에 '등(等)'으로만 언급되어 현행 천연소재 10종에 없는 항목:
- 모로오렌지추출물(**Morosil**, 체지방)
- 발효홍삼(fermented red ginseng), 진생베리(ginseng berry) — 홍삼 계열

'등'은 예시 나열이며 개별인정 근거 세트가 현재 자료에 없어, 사용자 결정대로 **추가하지 않고 기록만** 함. 향후 정식 편입 시 근거(논문·개별인정)와 함께 별도 추가 권장.
